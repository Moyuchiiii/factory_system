## 概要

AIを使った副業・収益化アイデアを体系的にまとめた中国語ベースのハンドブック。英語・日本語・韓国語のREADMEも用意されており、358コミットで継続的に更新されている。「プログラマーの副業宝典」「スタートアップ創業期の悩み相談」の2サブセクションを含む。具体的な収益額や事例の記載はなく、戦略・アイデア集としての位置づけ。

## AI収益化モデル一覧

### テクノロジー系
- AIラッパーサイト・API中継サービスの構築
- ニッチ特化のバーティカルSaaS（サブスクリプション型）
- エンタープライズ向けAgentワークフロー自動化
- ChatGPTなどのプライベートデプロイ代行
- Claude CodeやAIツールのインストール代行サービス
- Shopify / WordPress 向けプラグイン開発
- コードレビューツール・API擬似サービス

### コンテンツ・メディア系
- AI生成の絵本・ストーリー動画（スクリプト→動画化）
- バーチャルアバター解説動画
- 映画あらすじ解説コンテンツ
- 海外動画の翻訳・ローカライズ再利用
- Amazon KDP への AI書籍セルフパブリッシング（ドル収入）

### ビジュアル系
- カスタムアバター・壁紙生成
- 商品広告画像・プロダクトモックアップ
- 子ども向けイラスト本
- ロゴ制作・ステッカー生成
- 写真修復・家具シミュレーション

### オーディオ・配信系
- ボイスクローニングサービス
- ロイヤリティフリー楽曲生成
- 無人AIライブ配信（バーチャルプレゼンター）

### データ・コンサル系
- ニッチ業界データセットの販売（インフルエンサーリスト等）
- 中小企業向けAIコスト削減コンサルティング
- エンタープライズAIツール導入支援

### ライティング系
- SNS投稿コピーライティング代行
- 論文編集・レジュメ最適化
- 脚本・小説生成補助

## factory での活用方法

- `/research` でAI系ビジネスアイデアを探す際のアイデアプールとして参照する
- 「何を自動化・サービス化できるか」の発想起点として使う
- バーティカルSaaS・エンタープライズ自動化・コンテンツ量産系は Claude Code との相性が高い
- 「早期スタートアップの悩み相談」セクションは受注提案のコンテキスト把握にも使える

## 注目アイデア（Claude Codeで実現しやすいもの）

| アイデア | なぜ相性が良いか |
|---|---|
| エンタープライズAgentワークフロー自動化 | Claude Codeそのものが武器になる。案件単価も高め |
| AIツールのインストール代行 | 技術ハードルが高い人向けに需要あり。CWでそのまま受注できる |
| ニッチSaaSのMVP開発 | Claude Codeで高速プロトタイプ→受注・サブスク化 |
| Amazon KDP 書籍量産 | Claude Codeで生成→フォーマット→出版パイプラインを自動化できる |
| SNSコピーライティング自動化ツール | 繰り返し需要あり。SaaS化しやすい |
| 海外動画翻訳・ローカライズ | Claude APIとの組み合わせで高品質化 |

## 注意点

- **収益データなし**: 具体的な収入例・実績数値の記載はゼロ。アイデア集であり再現性の保証はない
- **中国語コンテンツ中心**: サブフォルダの詳細記事は中国語のみ。英語READMEは概要レベル
- **最終更新が2024年11月**: AIツールの進化速度を考えると一部アイデアは古い可能性あり。特にラッパーサイト系は競合飽和しやすい
- **倫理リスクに注意**: アカウント販売・カード販売系の記述あり（利用規約・法律リスクあり）。そのままサービス展開するのは避けること
- **「金を掘るより道具を売れ」哲学**: リポジトリ全体のトーンとして、直接AIで稼ぐよりAI活用を支援するサービス側に立つことを推奨している
